# Data and code availability statement template

Replace every angle-bracketed field before manuscript submission.

> All custom code used for the dosage-response and qPCR--bulk RNA-seq analyses
> reported in this paper
> is available at <GitHub repository URL>. The exact version used for the
> manuscript has been archived at <permanent archive URL and DOI>. The analyses
> were run with commit <full Git commit>. Source data are available from
> <repository and accession or DOI>. The commands linking each manuscript
> figure and table to its input and output are documented at <path in the
> archived repository>. Any additional information required to reanalyze the
> data reported in this paper is available from the lead contact upon request.

Before freezing the statement:

1. Create a versioned GitHub release for the submitted manuscript.
2. Archive that release in a preservation repository and obtain a DOI.
3. Replace the data placeholder with a public accession, or state and justify
   any ethical or legal access restriction.
4. Add a figure-to-command table and test every command from a clean clone.
5. Ensure the manuscript's Key Resources Table cites R, this repository, the
   archived release, and all upstream data resources.
